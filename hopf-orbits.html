Every orbit sits on one Floquet axis. Below 0 it is hyperbolic, between 0 and 1 elliptic, above 1 inverse-hyperbolic. Reaching 0 is a fold, where two orbits meet and vanish; crossing 1 is a period doubling.

As written, and with 0.1·x⁴ added, every term of V₁ is even in (q, p), so each orbit's monodromy is the square of a half-period map and can touch 1 but never cross it. Where the half-period map doubles instead (random 13, at ε ≈ 1.87 as written and 2.04 with x⁴), a mirror pair of new orbits appears.

With an odd term added, the squaring is gone and orbits that only touched 1 cross it, turning inverse-hyperbolic with no pair spawned. How far they cross follows how strongly the symmetry is broken. With 0.5·x³ the crossings are deep, down to k = −10. With 0.1·x⁵ they are shallow: in random 13 one orbit is inverse-hyperbolic only between ε = 1.46 and 1.79, and at most 6 × 10⁻⁴ past −4, still well above the numerical noise of 10⁻⁷. In all four systems E − H drifts while E + I − H stays at 2.

T² · charge on a flat torus · uniform magnetic field

On a torus, the count is zero

Every orbit of a charge in a uniform field is a cyclotron circle with the same period, so orbits are labeled by their centers, and the centers fill a torus. Averaging a weak potential over a circle of radius ρ multiplies each Fourier mode by J₀(|k|ρ). Near a zero of J₀ a mode switches off and returns with the opposite sign, so critical points are created and destroyed. The torus has χ = 0, so E + I − H should stay 0 however many there are.

S²(1,2) · 1:2 resonance · Fermi coupling κ

One orbit can be bad

With frequencies 1 and 2, every orbit has period 2π except the y-mode, which closes in half the time and sits at a cone point of the orbit space. Counted at period 2π it appears as a double cover. The rule from Frauenfelder, Koh and Moreno leaves a double cover out when the orbit itself is negative-hyperbolic. The coupling κ·x²y pushes the y-mode into its parametric-resonance tongue near κ* = 1.125, which is exactly that case.

Theory

What is proven, and what is only checked

The count is a theorem

χSFT = #good positive-hyperbolic − #(elliptic + negative-hyperbolic)

This is the SFT-Euler characteristic of Frauenfelder, Koh and Moreno, which is −(E + I − H) in the notation here. Elliptic and negative-hyperbolic orbits have odd Conley–Zehnder index and positive-hyperbolic ones even, which is why E groups with I against H. It cannot change through a bifurcation, by invariance of local Floer homology. At small ε its value is set by the averaged function: the Euler characteristic of the orbit space.

What the experiments add

They run that bookkeeping on systems it had not been run on: the pair born at a symmetric doubling, inverse-hyperbolic parents once the symmetry is broken, zero on a torus as J₀ reshapes the landscape, and the one bad orbit at a 1:2 resonance. Every index count held. The one prediction that failed was averaging's list of orbits on the torus, next to its own degeneracies. That checks the numerics against the theorem; it does not prove anything new.

What a proof here would need

A rigorous count at small ε (averaging with explicit bounds), the invariance theorem, and a proof that no periodic orbit enters or leaves the period window across the sweep. Each listed orbit's existence and type can be proven with interval arithmetic: a Krawczyk test on the shooting map and an enclosure of tr M − 4 away from 0 and −4.

Where it comes from

Weinstein and Moser for the small-ε count on S²; Ginzburg for at least four orbits of a charge on a flat torus at low energy; Frauenfelder, Koh and Moreno (2022) for χSFT, good and bad orbits, and the generic bifurcations it survives.

The 21 perturbations at ε = 0.01

Python script check_hopf.py. Periodic orbits are solved on the perturbed energy surface H = H₀ + εV₁ = ½. A case passes only if every check holds:

  1. The analytic ⟨V₁⟩ matches a direct 64-point average over Hopf circles (worst error 4.4 × 10⁻¹⁶).
  2. The critical points found by seeded Newton match an exact enumeration that cannot miss roots (bisection on the secular equation for the Lagrange multiplier). Extrema − saddles = 2.
  3. Each critical point continues to a periodic orbit of the full 4D flow (Newton shooting with the period free). The closure residual is below 10⁻¹⁰, and |H − ½| is below 10⁻¹⁰. Re-integrating at 100× tighter tolerance keeps the residual below 10⁻⁹.
  4. Floquet multipliers come from the monodromy matrix. Every extremum is elliptic, every saddle hyperbolic, none inverse-hyperbolic. At the tighter tolerance, tr M − 4 changes by less than 2 × 10⁻⁸ of its value. κ, the measured multiplier rate divided by ε√|h₁h₂|, should be 4 according to averaging; it comes out 3.74–4.00, and the gap halves when ε halves.
  5. Blind search, on the five named cases: Newton shooting from 400 seeds, with no use of ⟨V₁⟩, reached every predicted orbit and converged to nothing else. This is a search result for orbits near period 2π, not a proof that no other orbits exist.

Checks on this page's own code. The in-browser solver for the sphere's critical points agreed with the exact enumeration on 5,000 random slider settings and 2,200 settings near saddle-node bifurcations, disagreeing only where two points were 3 × 10⁻⁶ rad apart, which it labels degenerate. """Perturbed 1:1 oscillator on the Hopf base S^2.
Claim: periodic orbits near period 2*pi on one energy level satisfy
#elliptic - #hyperbolic = chi(S^2) = 2.
H = (px^2+py^2+x^2+y^2)/2 + EPS*V1,
V1 = x^4 + y^4 + c x^2 y^2 + d (x^2-y^2) + e x y + r (x py - y px).
"""
import json, time
import numpy as np
from scipy.integrate import solve_ivp

EPS, S0, H_LEVEL = 0.01, 1.0, 0.5
rng = np.random.default_rng(0)


class Sys:
    def __init__(s, c, d, e, r):
        s.p = dict(c=c, d=d, e=e, r=r)
        s.c, s.d, s.e, s.r = c, d, e, r

    def V1(s, X):
        x, y, px, py = X
        return x**4 + y**4 + s.c*x*x*y*y + s.d*(x*x - y*y) + s.e*x*y + s.r*(x*py - y*px)

    def H(s, X):
        x, y, px, py = X
        return 0.5*(px*px + py*py + x*x + y*y) + EPS*s.V1(X)

    def rhs(s, X):
        x, y, px, py = X
        c, d, e, r = s.c, s.d, s.e, s.r
        return np.array([px - EPS*r*y,
                         py + EPS*r*x,
                         -x - EPS*(4*x**3 + 2*c*x*y*y + 2*d*x + e*y + r*py),
                         -y - EPS*(4*y**3 + 2*c*x*x*y - 2*d*y + e*x - r*px)])

    def jac(s, X):
        x, y, px, py = X
        c, d, e, r = s.c, s.d, s.e, s.r
        J = np.zeros((4, 4))
        J[0, 1], J[0, 2] = -EPS*r, 1
        J[1, 0], J[1, 3] = EPS*r, 1
        J[2, 0] = -1 - EPS*(12*x*x + 2*c*y*y + 2*d)
        J[2, 1] = -EPS*(4*c*x*y + e)
        J[2, 3] = -EPS*r
        J[3, 0] = -EPS*(4*c*x*y + e)
        J[3, 1] = -1 - EPS*(12*y*y + 2*c*x*x - 2*d)
        J[3, 2] = EPS*r
        return J

    def gradH(s, X):
        f = s.rhs(X)
        return np.array([-f[2], -f[3], f[0], f[1]])

    # averaged V1 on the Hopf base: f(u) = u.A.u + b.u + const, u = unit Stokes vector
    def Ab(s):
        A = S0**2*np.diag([(3 - s.c/2)/16, s.c/16, 0.0])
        b = S0*np.array([s.d/2, s.e/4, s.r/2])
        const = S0**2*(3/16 + s.c/32)
        return A, b, const


def lift(u):
    u = u/np.linalg.norm(u)
    a = np.sqrt(S0*(1 + u[0])/2)
    b = np.sqrt(S0*max(1 - u[0], 0)/2)*np.exp(1j*np.arctan2(u[2], u[1]))
    return np.array([a.real, b.real, a.imag, b.imag])  # x, y, px, py


def hopf(X):
    x, y, px, py = X
    a, b = x + 1j*px, y + 1j*py
    ab = np.conj(a)*b
    S = np.array([abs(a)**2 - abs(b)**2, 2*ab.real, 2*ab.imag])
    return S/np.linalg.norm(S, axis=0)


def fib(n):
    i = np.arange(n) + 0.5
    z = 1 - 2*i/n
    t = np.pi*(1 + 5**0.5)*i
    return np.stack([np.sqrt(1 - z*z)*np.cos(t), np.sqrt(1 - z*z)*np.sin(t), z], 1)


# ---- S1: analytic average vs numerical average over Hopf circles
def check_average(sy, n=50):
    A, b, k = sy.Ab()
    th = np.linspace(0, 2*np.pi, 64, endpoint=False)
    err = 0.0
    for u in rng.normal(size=(n, 3)):
        u /= np.linalg.norm(u)
        X = lift(u)
        za, zb = (X[0] + 1j*X[2])*np.exp(-1j*th), (X[1] + 1j*X[3])*np.exp(-1j*th)
        num = sy.V1(np.array([za.real, zb.real, za.imag, zb.imag])).mean()
        err = max(err, abs(num - (u@A@u + b@u + k)))
    return err


# ---- S2: critical points of the averaged function on S^2
def critical_points(sy):
    A, b, _ = sy.Ab()
    out = []
    for u in fib(400):
        lam = u@(2*A@u + b)
        for _ in range(60):
            F = np.concatenate([2*A@u + b - lam*u, [u@u - 1]])
            if np.linalg.norm(F) < 1e-14:
                break
            J = np.zeros((4, 4))
            J[:3, :3] = 2*A - lam*np.eye(3)
            J[:3, 3] = -u
            J[3, :3] = 2*u
            try:
                st = np.linalg.solve(J, -F)
            except np.linalg.LinAlgError:
                break
            u, lam = u + st[:3], lam + st[3]
        if np.linalg.norm(F) > 1e-12 or any(np.linalg.norm(u - v["u"]) < 1e-6 for v in out):
            continue
        t1 = np.cross(u, [1, 0, 0] if abs(u[0]) < 0.9 else [0, 1, 0]); t1 /= np.linalg.norm(t1)
        t2 = np.cross(u, t1)
        T = np.stack([t1, t2], 1)
        ev = np.linalg.eigvalsh(T.T@(2*A - lam*np.eye(3))@T)
        kind = "min" if ev.min() > 0 else "max" if ev.max() < 0 else "saddle"
        out.append(dict(u=u, kind=kind, hess=ev))
    return out


# ---- S2b: exact enumeration, independent of Newton seeding.
# (p_k - lam) u_k = -b_k with p = 2 diag(A), so |u| = 1 becomes g(lam) = sum b_k^2/(p_k - lam)^2 - 1 = 0.
# g is monotone outside the poles (one root each side) and convex between adjacent poles (0 or 2 roots),
# so bisection on each interval finds every root. b_k = 0 adds solutions at lam = p_k.
# Returns (points, gap); gap -> 0 at a saddle-node of <V1>. Returns None for a circle of critical points.
def algebraic_critical(sy):
    A, b, _ = sy.Ab()
    p = 2*np.diag(A)
    act = [k for k in range(3) if b[k] != 0]
    g = lambda l: sum(b[k]**2/(p[k] - l)**2 for k in act) - 1
    dg = lambda l: sum(2*b[k]**2/(p[k] - l)**3 for k in act)

    def bis(f, lo, hi):  # needs f < 0 near lo, f > 0 near hi; never evaluates the endpoints
        for _ in range(400):
            m = 0.5*(lo + hi)
            if m <= lo or m >= hi:
                break
            lo, hi = (m, hi) if f(m) < 0 else (lo, m)
        return 0.5*(lo + hi)

    lams, gap = [], np.inf
    q = sorted(set(p[k] for k in act))
    if q:
        R = 2*np.linalg.norm(b) + 1
        lams += [bis(g, q[0] - R, q[0]), bis(lambda l: -g(l), q[-1], q[-1] + R)]
        for lo, hi in zip(q, q[1:]):
            ls = bis(dg, lo, hi)
            gm = g(ls)
            gap = min(gap, abs(gm))
            if gm < 0:
                lams += [bis(lambda l: -g(l), lo, ls), bis(g, ls, hi)]
    pts = [np.array([-b[k]/(p[k] - l) if b[k] != 0 else 0.0 for k in range(3)]) for l in lams]
    for k in range(3):
        if b[k] != 0:
            continue
        l = p[k]
        if any(j != k and p[j] == l for j in range(3)):
            if any(j != k and p[j] == l and b[j] == 0 for j in range(3)):
                return None
            continue
        u = np.array([-b[j]/(p[j] - l) if j != k and b[j] != 0 else 0.0 for j in range(3)])
        rem = 1 - u@u
        gap = min(gap, abs(rem))
        if rem > 0:
            for s in (1, -1):
                v = u.copy(); v[k] = s*np.sqrt(rem); pts.append(v)
    return pts, gap


# ---- S3: periodic orbits of the full system by Newton shooting
def flow(sy, X0, T, stm=True, rtol=1e-11):
    if not stm:
        return solve_ivp(lambda t, X: sy.rhs(X), (0, T), X0, method="DOP853",
                         rtol=1e-11, atol=1e-12, dense_output=True)
    def f(t, Y):
        return np.concatenate([sy.rhs(Y[:4]), (sy.jac(Y[:4])@Y[4:].reshape(4, 4)).ravel()])
    Y = solve_ivp(f, (0, T), np.concatenate([X0, np.eye(4).ravel()]),
                  method="DOP853", rtol=rtol, atol=rtol/10).y[:, -1]
    return Y[:4], Y[4:].reshape(4, 4)


def shoot(sy, X, T=2*np.pi, maxit=40, maxstep=0.1):
    for _ in range(maxit):
        XT, M = flow(sy, X, T)
        F = np.concatenate([XT - X, [sy.H(X) - H_LEVEL], [0.0]])
        if np.linalg.norm(F) < 1e-10:
            return dict(X=X, T=T, M=M, res=np.linalg.norm(F))
        J = np.zeros((6, 5))
        J[:4, :4] = M - np.eye(4)
        J[:4, 4] = sy.rhs(XT)
        J[4, :4] = sy.gradH(X)
        J[5, :4] = sy.rhs(X)
        dz = np.linalg.lstsq(J, -F, rcond=None)[0]
        n = np.linalg.norm(dz)
        if n > maxstep:
            dz *= maxstep/n
        X, T = X + dz[:4], T + dz[4]
    return None


def orbit_center(sy, orb):
    sol = flow(sy, orb["X"], orb["T"], stm=False)
    S = hopf(sol.sol(np.linspace(0, orb["T"], 64, endpoint=False))).mean(1)
    return S/np.linalg.norm(S)


def floquet(orb):
    k = np.trace(orb["M"]) - 4          # = lambda + 1/lambda - 2 for the nontrivial multiplier pair
    return ("elliptic" if -4 < k < 0 else "hyperbolic" if k > 0 else "inverse-hyperbolic"), k


def blind_search(sy, nseed=400):  # max basins can be ~0.1 rad wide; 400 seeds ≈ 0.1 rad apart
    found = []
    for u in fib(nseed):
        orb = shoot(sy, lift(u))
        if orb is None:
            continue
        cen = orbit_center(sy, orb)
        if all(np.linalg.norm(cen - f["center"]) > 0.05 for f in found):
            found.append(dict(center=cen, type=floquet(orb)[0]))
    return found


def run_case(name, params, blind=False):
    sy = Sys(**params)
    cps = critical_points(sy)
    n_ext = sum(c["kind"] != "saddle" for c in cps)
    n_sad = sum(c["kind"] == "saddle" for c in cps)
    rows, ok = [], True
    for cp in cps:
        orb = shoot(sy, lift(cp["u"]))
        if orb is None:
            ok = False
            rows.append(dict(kind=cp["kind"], converged=False))
            continue
        cen = orbit_center(sy, orb)
        typ, k = floquet(orb)
        match = (typ == "elliptic") == (cp["kind"] != "saddle") and typ != "inverse-hyperbolic"
        ok &= match
        XT2, M2 = flow(sy, orb["X"], orb["T"], rtol=1e-13)       # same orbit, 100x tighter tolerance
        k2 = floquet(dict(M=M2))[1]
        # averaging predicts multiplier angle (elliptic) or exponent (hyperbolic) = 4*eps*sqrt|h1 h2| per unit time
        ang = np.arccos(1 + k/2) if typ == "elliptic" else np.arccosh(1 + k/2) if typ == "hyperbolic" else np.nan
        kappa = ang/(orb["T"]*EPS*np.sqrt(abs(np.prod(cp["hess"]))))
        rows.append(dict(kind=cp["kind"], u=cp["u"].round(4).tolist(), floquet=typ,
                         trM_minus_4=float(k), trM_minus_4_tight=float(k2), T=float(orb["T"]), res=float(orb["res"]),
                         res_tight=float(np.linalg.norm(XT2 - orb["X"])), dH=float(abs(sy.H(orb["X"]) - H_LEVEL)),
                         kappa=float(kappa), shift=float(np.linalg.norm(cen - cp["u"])), match=bool(match),
                         center=cen))
    n_ell = sum(r.get("floquet") == "elliptic" for r in rows)
    n_hyp = sum(r.get("floquet") == "hyperbolic" for r in rows)
    centers = [r["center"] for r in rows if "center" in r]
    distinct = all(np.linalg.norm(a - b) > 0.05 for i, a in enumerate(centers) for b in centers[i+1:])
    out = dict(name=name, params=params, n_ext=n_ext, n_saddle=n_sad,
               n_elliptic=n_ell, n_hyperbolic=n_hyp, distinct=bool(distinct),
               max_res=max((r.get("res", 1) for r in rows), default=1),
               max_shift=max((r.get("shift", 9) for r in rows), default=9),
               types_match=bool(ok))
    alg = algebraic_critical(sy)
    out["alg_count"] = None if alg is None else len(alg[0])
    out["alg_match"] = bool(alg is not None and len(alg[0]) == len(cps) and all(
        any(np.linalg.norm(a - c["u"]) < 1e-8 for a in alg[0]) for c in cps))
    out["max_dH"] = max((r.get("dH", 1) for r in rows), default=1)
    out["max_res_tight"] = max((r.get("res_tight", 1) for r in rows), default=1)
    out["min_floquet_snr"] = min((abs(r["trM_minus_4"])/max(abs(r["trM_minus_4"] - r["trM_minus_4_tight"]), 1e-300)
                                  for r in rows if "trM_minus_4" in r), default=0)
    ks = [r["kappa"] for r in rows if "kappa" in r]
    out["kappa_range"] = [min(ks), max(ks)] if ks else None
    if blind:
        bf = blind_search(sy)
        same = len(bf) == len(centers) and all(
            any(np.linalg.norm(f["center"] - c) < 0.05 for c in centers) for f in bf)
        out["blind_found"] = len(bf)
        out["blind_matches"] = bool(same)
    for r in rows:
        r.pop("center", None)
    out["orbits"] = rows
    return out


def well_separated(params):
    cps = critical_points(Sys(**params))
    if any(abs(c["hess"]).min() < 2e-3 for c in cps):
        return False
    us = [c["u"] for c in cps]
    return all(np.linalg.norm(a - b) > 0.2 for i, a in enumerate(us) for b in us[i+1:])

"""eps sweep for the perturbed 1:1 oscillator of check_hopf.py, on the energy surface H = 1/2.

Every term of V1 is even, so P(q, p) = -(q, p) is a symmetry. An orbit is symmetric if flow(T/2)(X) = -X.
For those, G = P o flow(T/2) fixes X and the monodromy is M = (DG)^2, so M cannot have a negative real multiplier.

Classification (k = tr - 4 of the nontrivial multiplier pair; E elliptic, H hyperbolic, I inverse-hyperbolic):
  full     k  = tr M - 4          every orbit of period ~T
  quotient k' = tr DG - 4 = -tr flow'(T/2) - 4    symmetric orbits only
Predictions, fixed before the run:
  P1  quotient: E'-H' = 2 until the first I' (mu = -1 of G); E'+I'-H' = 2 at every eps
  P2  full: no symmetric orbit is ever I; E+I-H = 2 over all orbits of period ~T, nonsymmetric pairs included

def stm(sy, X, T, rtol):
    def f(t, Y):
        return np.concatenate([sy.rhs(Y[:4]), (sy.jac(Y[:4]) @ Y[4:].reshape(4, 4)).ravel()])
    s = solve_ivp(f, (0, T), np.concatenate([X, np.eye(4).ravel()]), method="DOP853",
                  rtol=rtol, atol=rtol/10, t_eval=[T/2, T])
    return [(s.y[:4, i], s.y[4:, i].reshape(4, 4)) for i in range(2)]


def kind(k, dk):
    if min(abs(k), abs(k + 4)) < max(1e3*dk, 1e-8):
        return "unsure"
    return "E" if -4 < k < 0 else "H" if k > 0 else "I"


def signature(sy, X, T):
    pts = h.flow(sy, X, T, stm=False).sol(np.linspace(0, T, 128, endpoint=False))
    c = h.hopf(pts).mean(1)
    return dict(T=float(T), center=c/np.linalg.norm(c), mean=pts.mean(1))

def describe(sy, X, T, sig=None):
    (Xh, Mh), (XT, M) = stm(sy, X, T, 1e-11)
    (_, Mh2), (_, M2) = stm(sy, X, T, 1e-13)
    k, k2 = np.trace(M) - 4, np.trace(M2) - 4
    d = dict(sig or signature(sy, X, T), X=X, res=float(np.linalg.norm(XT - X)),
             dH=float(abs(sy.H(X) - h.H_LEVEL)), sym=float(np.linalg.norm(Xh + X)),
             k=float(k), full=kind(k, abs(k - k2)))
    if d["sym"] < 1e-7:
        q, q2 = -np.trace(Mh) - 4, -np.trace(Mh2) - 4
        d.update(kq=float(q), quot=kind(q, abs(q - q2)), square_err=float(abs((q + 2)**2 - 4 - k)))
        w, v = np.linalg.eig(-Mh)                       # DG; eigenvector for the multiplier nearest -1
        d["v_pd"] = np.real(v[:, np.argmin(abs(w + 1))])
    return d


# ---- symmetric shooting: solve flow(T/2)(X) = -X. Its Jacobian flow'(T/2) + I = I - DG stays nonsingular
# through mu = -1 of G, where full-period shooting (M - I, M = DG^2) is singular and can jump to the new pair.
def shoot_sym(sy, X, T, maxit=40, maxstep=0.1):
    for _ in range(maxit):
        Xh, Mh = h.flow(sy, X, T/2)
        F = np.concatenate([Xh + X, [sy.H(X) - h.H_LEVEL], [0.0]])
        if np.linalg.norm(F) < 1e-10:
            return dict(X=X, T=T)
        J = np.zeros((6, 5))
        J[:4, :4], J[:4, 4] = Mh + np.eye(4), 0.5*sy.rhs(Xh)
        J[4, :4], J[5, :4] = sy.gradH(X), sy.rhs(X)
        dz = np.linalg.lstsq(J, -F, rcond=None)[0]
        dz *= min(1, maxstep/np.linalg.norm(dz))
        X, T = X + dz[:4], T + dz[4]
    return None


# ---- continuation of each averaged critical point's orbit in eps (secant predictor, step halving)
def advance(sy, path, e_target):
    while path[-1][0] < e_target:
        e0, X0, T0 = path[-1]
        step = e_target - e0
        while True:
            e1 = e_target if step >= e_target - e0 else e0 + step
            if len(path) >= 2:
                ea, Xa, Ta = path[-2]
                w = (e1 - e0)/(e0 - ea)
                Xg, Tg = X0 + w*(X0 - Xa), T0 + w*(T0 - Ta)
            else:
                Xg, Tg = X0, T0
            h.EPS = e1
            o = shoot_sym(sy, Xg, Tg)
            if o is not None and np.linalg.norm(o["X"] - Xg) < 0.05 and abs(o["T"] - Tg) < 0.05:
                path.append((e1, o["X"], o["T"]))
                del path[:-2]
                break
            step /= 2
            if step < 1e-7:
                return False
    return True

# ---- batched Newton shooting: all seeds integrated together as one ODE in normalized time tau = t/T
def jac_v(sy, X):
    x, y, px, py = X
    E, c, d, e, r = h.EPS, sy.c, sy.d, sy.e, sy.r
    J = np.zeros((X.shape[1], 4, 4))
    J[:, 0, 1], J[:, 0, 2], J[:, 1, 0], J[:, 1, 3] = -E*r, 1, E*r, 1
    J[:, 2, 0] = -1 - E*(12*x*x + 2*c*y*y + 2*d)
    J[:, 2, 1] = J[:, 3, 0] = -E*(4*c*x*y + e)
    J[:, 2, 3], J[:, 3, 2] = -E*r, E*r
    J[:, 3, 1] = -1 - E*(12*y*y + 2*c*x*x - 2*d)
    return J


def batch_flow(sy, X, T, dense=0):
    n = len(T)
    def f(tau, Y):
        Y = Y.reshape(n, 20)
        Xs = Y[:, :4].T
        dX = sy.rhs(Xs).T*T[:, None]
        dP = T[:, None, None]*(jac_v(sy, Xs) @ Y[:, 4:].reshape(n, 4, 4))
        return np.concatenate([dX, dP.reshape(n, 16)], 1).ravel()
    Y0 = np.concatenate([X, np.tile(np.eye(4).ravel(), (n, 1))], 1).ravel()
    tev = np.linspace(0, 1, dense, endpoint=False) if dense else [1.0]
    s = solve_ivp(f, (0, 1), Y0, method="DOP853", rtol=1e-11, atol=1e-12, t_eval=tev).y.reshape(n, 20, -1)
    return s if dense else (s[:, :4, -1], s[:, 4:, -1].reshape(n, 4, 4))


def batch_shoot(sy, X, T, maxit=40, maxstep=0.1):
    X, T, T0 = np.array(X), np.array(T, float), np.array(T, float)
    act, done, best = np.ones(len(T), bool), np.zeros(len(T), bool), np.full(len(T), np.inf)
    for it in range(maxit):
        idx = np.where(act)[0]
        if not len(idx):
            break
        XT, M = batch_flow(sy, X[idx], T[idx])
        for j, i in enumerate(idx):
            F = np.concatenate([XT[j] - X[i], [sy.H(X[i]) - h.H_LEVEL], [0.0]])
            nf = np.linalg.norm(F)
            if nf < 1e-9:
                act[i], done[i] = False, True
                continue
            best[i] = min(best[i], nf)
            if not np.isfinite(nf) or (it >= 15 and nf > 1e-3) or np.abs(X[i]).max() > 5 or abs(T[i] - T0[i]) > 0.5*T0[i]:
                act[i] = False
                continue
            Jm = np.zeros((6, 5))
            Jm[:4, :4], Jm[:4, 4] = M[j] - np.eye(4), sy.rhs(XT[j])
            Jm[4, :4], Jm[5, :4] = sy.gradH(X[i]), sy.rhs(X[i])
            dz = np.linalg.lstsq(Jm, -F, rcond=None)[0]
            dz *= min(1, maxstep/np.linalg.norm(dz))
            X[i], T[i] = X[i] + dz[:4], T[i] + dz[4]
    return X[done], T[done]

orbits.pysystem-agnostic shooting, Floquet, continuation and search
"""Generic periodic-orbit toolkit for two-degree-of-freedom Hamiltonian flows (state X in R^4).
The methods of check_hopf.py / sweep_hopf.py, made system-agnostic for torus_exp.py and res12_exp.py:
Newton shooting with energy and phase conditions; Floquet type from k = tr M - 4 at two tolerances;
detection of double covers (orbit closes at T/2) with the prime orbit's type; batched shooting for blind
searches; secant continuation with step halving; bisection of events; a parallel sweep driver.

An experiment module provides: make(p) -> system, E(p) -> energy, seeds(p, sy) -> [(X, T guess)], TWIN = (lo, hi).
A system provides: rhs(X), jacv(X[4, n]) -> [n, 4, 4], H(X), gradH(X), wrap(dX), canon(mean), ok(X).
"""
import importlib
import numpy as np
from multiprocessing import Pool
from scipy.integrate import solve_ivp


def stm(sy, X, T, rtol=1e-11):
    def f(t, Y):
        return np.concatenate([sy.rhs(Y[:4]), (sy.jacv(Y[:4, None])[0] @ Y[4:].reshape(4, 4)).ravel()])
    s = solve_ivp(f, (0, T), np.concatenate([X, np.eye(4).ravel()]), method="DOP853",
                  rtol=rtol, atol=rtol/10, t_eval=[T/2, T])
    return [(s.y[:4, i], s.y[4:, i].reshape(4, 4)) for i in (0, 1)]


def shoot(sy, X, T, E, maxit=40, maxstep=0.1):
    """Newton on X(T) - X = 0 with H(X) = E and a phase condition; returns (X, T) or None."""
    X = np.array(X, float)
    for _ in range(maxit):
        XT, M = stm(sy, X, T)[1]
        F = np.concatenate([sy.wrap(XT - X), [sy.H(X) - E], [0.0]])
        if np.linalg.norm(F) < 1e-10:
            return X, T
        J = np.zeros((6, 5))
        J[:4, :4], J[:4, 4] = M - np.eye(4), sy.rhs(XT)
        J[4, :4], J[5, :4] = sy.gradH(X), sy.rhs(X)
        dz = np.linalg.lstsq(J, -F, rcond=None)[0]
        dz *= min(1, maxstep/max(np.linalg.norm(dz), 1e-300))
        X, T = X + dz[:4], T + dz[4]
    return None


def kind(k, dk):
    if min(abs(k), abs(k + 4)) < max(1e3*dk, 1e-8):
        return "unsure"
    return "E" if -4 < k < 0 else "H" if k > 0 else "I"


def signature(sy, X, T):
    """Phase-independent orbit identity: period, mean state, and width (centred second moment). The width is what
    separates a newborn period-doubled orbit from the double cover it was born from: their periods and means agree
    to ~1e-6 near the bifurcation, their widths do not."""
    P = batch_traj(sy, X[None], np.array([T]), 128)[0]
    return dict(T=float(T), mean=sy.canon(P.mean(1)), var=((P - P.mean(1, keepdims=True))**2).mean(1))


def same(sy, a, b):
    return (abs(a["T"] - b["T"]) < 1e-6 and np.linalg.norm(sy.wrap(np.subtract(a["mean"], b["mean"]))) < 1e-5
            and np.linalg.norm(np.subtract(a["var"], b["var"])) < 1e-7)


def describe(sy, X, T, E):
    (Xh, Mh), (XT, M) = stm(sy, X, T)
    (_, Mh2), (_, M2) = stm(sy, X, T, rtol=1e-13)
    k, k2 = np.trace(M) - 4, np.trace(M2) - 4
    d = dict(signature(sy, X, T), X=X, res=float(np.linalg.norm(sy.wrap(XT - X))), dH=float(abs(sy.H(X) - E)),
             k=float(k), type=kind(k, abs(k - k2)), half_res=float(np.linalg.norm(sy.wrap(Xh - X))))
    if d["half_res"] < 1e-7:                       # double cover of a period-T/2 orbit
        kh, kh2 = np.trace(Mh) - 4, np.trace(Mh2) - 4
        d.update(kh=float(kh), prime=kind(kh, abs(kh - kh2)))
        d["good"] = d["prime"] != "I"              # even covers of negative-hyperbolic orbits are bad
    return d


# ---- batched integration in normalized time tau = t/T
def batch_traj(sy, X, T, m):
    n = len(T)
    f = lambda tau, Y: (sy.rhs(Y.reshape(n, 4).T).T*T[:, None]).ravel()
    s = solve_ivp(f, (0, 1), np.asarray(X, float).ravel(), method="DOP853", rtol=1e-11, atol=1e-12,
                  t_eval=np.linspace(0, 1, m, endpoint=False))
    return s.y.reshape(n, 4, m)


def batch_flow(sy, X, T):
    n = len(T)
    def f(tau, Y):
        Y = Y.reshape(n, 20)
        Xs = Y[:, :4].T
        dX = sy.rhs(Xs).T*T[:, None]
        dP = T[:, None, None]*(sy.jacv(Xs) @ Y[:, 4:].reshape(n, 4, 4))
        return np.concatenate([dX, dP.reshape(n, 16)], 1).ravel()
    Y0 = np.concatenate([X, np.tile(np.eye(4).ravel(), (n, 1))], 1).ravel()
    Y = solve_ivp(f, (0, 1), Y0, method="DOP853", rtol=1e-11, atol=1e-12).y[:, -1].reshape(n, 20)
    return Y[:, :4], Y[:, 4:].reshape(n, 4, 4)


def batch_shoot(sy, E, X, T, maxit=40, maxstep=0.1):
    X, T, T0 = np.array(X, float), np.array(T, float), np.array(T, float)
    act, done = np.ones(len(T), bool), np.zeros(len(T), bool)
    for it in range(maxit):
        idx = np.where(act)[0]
        if not len(idx):
            break
        XT, M = batch_flow(sy, X[idx], T[idx])
        for j, i in enumerate(idx):
            F = np.concatenate([sy.wrap(XT[j] - X[i]), [sy.H(X[i]) - E], [0.0]])
            nf = np.linalg.norm(F)
            if nf < 1e-9:
                act[i], done[i] = False, True
                continue
            if not np.isfinite(nf) or (it >= 15 and nf > 1e-3) or not sy.ok(X[i]) or abs(T[i] - T0[i]) > 0.5*T0[i]:
                act[i] = False
                continue
            J = np.zeros((6, 5))
            J[:4, :4], J[:4, 4] = M[j] - np.eye(4), sy.rhs(XT[j])
            J[4, :4], J[5, :4] = sy.gradH(X[i]), sy.rhs(X[i])
            dz = np.linalg.lstsq(J, -F, rcond=None)[0]
            dz *= min(1, maxstep/max(np.linalg.norm(dz), 1e-300))
            X[i], T[i] = X[i] + dz[:4], T[i] + dz[4]
    return X[done], T[done]


def search(exp, p, rows):
    """Blind seeds from the experiment, plus seeds pushed off each known orbit along both transverse directions."""
    sy, E = exp.make(p), exp.E(p)
    seeds = list(exp.seeds(p, sy))
    for r in rows:
        Q = np.linalg.qr(np.column_stack([sy.gradH(r["X"]), sy.rhs(r["X"]), np.eye(4)]))[0]
        for v in (Q[:, 2], Q[:, 3]):
            for dl in (0.003, 0.01, 0.03, 0.1):
                seeds += [(r["X"] + dl*v, r["T"]), (r["X"] - dl*v, r["T"])]
    Xc, Tc = batch_shoot(sy, E, [s[0] for s in seeds], [s[1] for s in seeds])
    keep = (Tc > exp.TWIN[0]) & (Tc < exp.TWIN[1])
    Xc, Tc = Xc[keep], Tc[keep]
    found = []
    if len(Tc):
        P = batch_traj(sy, Xc, Tc, 128)
        for X, T, Pi in zip(Xc, Tc, P):
            s = dict(T=float(T), mean=sy.canon(Pi.mean(1)), var=((Pi - Pi.mean(1, keepdims=True))**2).mean(1), X=X)
            if not any(abs(s["T"] - f["T"]) < 1e-6 and np.linalg.norm(sy.wrap(s["mean"] - f["mean"])) < 1e-6
                       and np.linalg.norm(s["var"] - f["var"]) < 1e-7 for f in found):
                found.append(s)
    out = []
    for f in found:
        o = shoot(sy, f["X"], f["T"], E)
        if o is not None:
            d = describe(sy, o[0], o[1], E)
            if exp.TWIN[0] < d["T"] < exp.TWIN[1] and not any(same(sy, d, g) for g in out):
                out.append(d)
    return out


# ---- continuation in the experiment parameter p
def advance(exp, path, target):
    while path[-1][0] != target:
        p0, X0, T0 = path[-1]
        step = target - p0
        while True:
            p1 = target if abs(step) >= abs(target - p0) else p0 + step
            if len(path) >= 2:
                pa, Xa, Ta = path[-2]
                w = (p1 - p0)/(p0 - pa)
                Xg, Tg = X0 + w*(X0 - Xa), T0 + w*(T0 - Ta)
            else:
                Xg, Tg = X0, T0
            o = shoot(exp.make(p1), Xg, Tg, exp.E(p1), maxit=15)   # from a good predictor Newton needs < 10
            if o is not None and np.linalg.norm(o[0] - Xg) < 0.05 and abs(o[1] - Tg) < 0.05:
                path.append((p1, o[0], o[1]))
                del path[:-2]
                break
            step /= 2
            if abs(step) < 1e-5:
                return False
    return True


def branch_job(modname, grid, X, T, find_events):
    exp = importlib.import_module(modname)
    path, rows, end = [(grid[0], X, T)], [], None
    for p in grid:
        if not advance(exp, path, p):
            end = float(path[-1][0])
            break
        rows.append(dict(p=float(p), **describe(exp.make(p), path[-1][1], path[-1][2], exp.E(p))))
    ev = []
    if find_events:
        for key, thr, label in (("k", -4, "full-period doubling"), ("k", 0, "k crosses 0"),
                                ("kh", -4, "prime orbit doubles")):
            for r0, r1 in zip(rows, rows[1:]):
                if key in r0 and key in r1 and (r0[key] - thr)*(r1[key] - thr) < 0:
                    lo, hi, Xl, Tl = r0["p"], r1["p"], r0["X"], r0["T"]
                    for _ in range(30):
                        m, pth = 0.5*(lo + hi), [(lo, Xl, Tl)]
                        if not advance(exp, pth, m):
                            break
                        d = describe(exp.make(m), pth[-1][1], pth[-1][2], exp.E(m))
                        if key not in d:
                            break
                        if (d[key] - thr)*(r0[key] - thr) > 0:
                            lo, Xl, Tl = m, pth[-1][1], pth[-1][2]
                        else:
                            hi = m
                    ev.append((label, float(lo)))
        if end is not None:
            ev.append(("fold", end))
    return rows, end, ev


def search_job(modname, p, rows):

        return {k: tojson(v) for k, v in o.items()}
    if isinstance(o, (list, tuple)):

    if isinstance(o, np.ndarray):
        return o.tolist()
    if isinstance(o, (np.floating, np.integer, np.bool_)):

    return o

"""Charged particle on the flat torus [0, 2pi)^2 in a uniform magnetic field B = 1, perturbed by eps*V(q).
  dq/dt = v,   dv/dt = (v_y, -v_x) - eps*grad V(q),   energy |v|^2/2 + eps*V(q) = rho^2/2.
Unperturbed, every orbit is a cyclotron circle of radius rho and period 2pi, q = c + rho(sin t, cos t), so orbits
correspond to guiding centres c = (x + v_y, y - v_x) in T^2. Averaging V over the circle multiplies each Fourier mode
by J0(|k| rho):  <V>(c) = sum A J0(|k| rho) cos(k.c + phase). Centres drift along its contours, so extrema of <V>
give elliptic orbits and saddles hyperbolic ones; chi(T^2) = 0.

Predictions, fixed before any orbit was computed:
  T1  eps = 0.01, every rho: the full-system orbits match the critical points of <V> one to one, with types;
      E - H = 0; at least 4 orbits
  T2  rho sweep 0.3 -> 3.0 at eps = 0.01: the number of orbits changes, E + I - H = 0 at every counted rho
  T3  eps sweep at rho = 1.6, up to 0.9 of the eps where the speed could reach zero: E + I - H = 0 at every counted eps
"""
import numpy as np
from scipy.special import j0

MODES = [(1, 0, 1.0, 0.0), (0, 1, 0.7, 0.5), (1, 1, 0.5, 1.3), (2, -1, 0.3, 0.4), (1, -2, 0.25, 2.1)]
K = np.array([(m[0], m[1]) for m in MODES], float)
A = np.array([m[2] for m in MODES])
PH = np.array([m[3] for m in MODES])
TWO_PI = 2*np.pi
TWIN = (0.7*TWO_PI, 1.3*TWO_PI)
SWEEP = "rho"           # "rho": p = rho at EPS0; "eps": p = eps at RHO_E
EPS0, RHO_E = 0.01, 1.6


def V(x, y):
    return sum(a*np.cos(kx*x + ky*y + ph) for (kx, ky), a, ph in zip(K, A, PH))


def dV(x, y):
    s = [-a*np.sin(kx*x + ky*y + ph) for (kx, ky), a, ph in zip(K, A, PH)]
    return sum(si*kx for si, (kx, _) in zip(s, K)), sum(si*ky for si, (_, ky) in zip(s, K))


def ddV(x, y):
    c = [-a*np.cos(kx*x + ky*y + ph) for (kx, ky), a, ph in zip(K, A, PH)]
    return (sum(ci*kx*kx for ci, (kx, ky) in zip(c, K)), sum(ci*kx*ky for ci, (kx, ky) in zip(c, K)),
            sum(ci*ky*ky for ci, (kx, ky) in zip(c, K)))


VMAX = float(np.max(V(*np.meshgrid(np.linspace(0, TWO_PI, 801), np.linspace(0, TWO_PI, 801)))))
EPS_MAX = 0.9*(RHO_E**2/2)/VMAX


class Torus:
    def __init__(self, eps):
        self.eps = eps

    def rhs(self, X):
        x, y, vx, vy = X
        Vx, Vy = dV(x, y)
        return np.array([vx, vy, vy - self.eps*Vx, -vx - self.eps*Vy])

    def jacv(self, X):
        x, y = X[0], X[1]
        Vxx, Vxy, Vyy = ddV(x, y)
        J = np.zeros((X.shape[1], 4, 4))
        J[:, 0, 2] = J[:, 1, 3] = J[:, 2, 3] = 1
        J[:, 3, 2] = -1
        J[:, 2, 0], J[:, 2, 1] = -self.eps*Vxx, -self.eps*Vxy
        J[:, 3, 0], J[:, 3, 1] = -self.eps*Vxy, -self.eps*Vyy
        return J

    def H(self, X):
        return 0.5*(X[2]**2 + X[3]**2) + self.eps*V(X[0], X[1])

    def gradH(self, X):
        Vx, Vy = dV(X[0], X[1])
        return np.array([self.eps*Vx, self.eps*Vy, X[2], X[3]])

    def wrap(self, dX):
        dX = np.array(dX, float)
        dX[..., :2] = (dX[..., :2] + np.pi) % TWO_PI - np.pi
        return dX

    def canon(self, m):
        m = np.array(m, float)
        m[:2] %= TWO_PI
        return m

    def ok(self, X):
        return np.abs(X[2:]).max() < 10

# ---- averaged potential on T^2 and its critical points
def avg(c, rho, d=0):
    """<V>, its gradient (d=1) or Hessian (d=2) at guiding centre c = (cx, cy)."""
    w = A*j0(np.linalg.norm(K, axis=1)*rho)
    ph = np.asarray(c) @ K.T + PH
    if d == 0:
        return np.sum(w*np.cos(ph), axis=-1)
    if d == 1:
        s = -w*np.sin(ph)
        return np.stack([np.sum(s*K[:, 0], -1), np.sum(s*K[:, 1], -1)])
    co = -w*np.cos(ph)
    return np.array([[np.sum(co*K[:, 0]*K[:, 0]), np.sum(co*K[:, 0]*K[:, 1])],
                     [np.sum(co*K[:, 0]*K[:, 1]), np.sum(co*K[:, 1]*K[:, 1])]])


def avg_critical(rho, n=240):
    """Critical points of <V> by Newton from every grid cell whose gradient winding is nonzero and from every
    local minimum of |grad|^2; checked against the windings (a degree count over all cells)."""
    g = np.linspace(0, TWO_PI, n, endpoint=False)
    cx, cy = np.meshgrid(g, g, indexing="ij")
    C = np.stack([cx, cy], -1)
    G = avg(C, rho, 1)                                     # [2, n, n]
    ang = np.arctan2(G[1], G[0])
    def dang(a, b):
        return (b - a + np.pi) % TWO_PI - np.pi
    a00, a10, a11, a01 = ang, np.roll(ang, -1, 0), np.roll(np.roll(ang, -1, 0), -1, 1), np.roll(ang, -1, 1)
    wind = np.rint((dang(a00, a10) + dang(a10, a11) + dang(a11, a01) + dang(a01, a00))/TWO_PI).astype(int)
    g2 = G[0]**2 + G[1]**2
    locmin = np.ones_like(g2, bool)
    for sx in (-1, 0, 1):
        for sy in (-1, 0, 1):
            if sx or sy:
                locmin &= g2 <= np.roll(np.roll(g2, sx, 0), sy, 1)
    h = TWO_PI/n
    starts = [C[i, j] + h/2 for i, j in zip(*np.nonzero(wind))] + [C[i, j] for i, j in zip(*np.nonzero(locmin))]
    pts = []
    for c in starts:
        c = np.array(c, float)
        for _ in range(50):
            gr = avg(c, rho, 1)
            if np.linalg.norm(gr) < 1e-13:
                break
            try:
                c = c - np.linalg.solve(avg(c, rho, 2), gr)
            except np.linalg.LinAlgError:
                break
        if np.linalg.norm(avg(c, rho, 1)) > 1e-11:
            continue
        c %= TWO_PI
        if any(np.linalg.norm((c - q["c"] + np.pi) % TWO_PI - np.pi) < 1e-7 for q in pts):
            continue
        Hs = avg(c, rho, 2)
        dt, tr = np.linalg.det(Hs), np.trace(Hs)
        pts.append(dict(c=c, kind="saddle" if dt < 0 else ("min" if tr > 0 else "max"), det=float(dt)))
    # degree check: every cell with nonzero winding holds points whose indices sum to that winding
    idx = np.zeros_like(wind)
    for q in pts:
        i, j = (np.floor(q["c"]/h).astype(int)) % n
        idx[i, j] += -1 if q["kind"] == "saddle" else 1
    return pts, bool(np.array_equal(idx, wind)), int(wind.sum())


def seeds(p, sy):
    rho, eps = rho_eps(p)
    cs = [q["c"] for q in avg_critical(rho)[0]] + \

        if sp2 > 0:
            out.append((np.array([x, y, np.sqrt(sp2), 0.0]), TWO_PI))
    return out
res12_exp.py1:2 resonance with Fermi coupling
"""1:2 resonance:  H = (px^2 + x^2)/2 + (py^2 + 4 y^2)/2 + eps*V1,
  V1 = kappa x^2 y + d (x^2 - y^2) + x^4 + y^4 + c x^2 y^2 + g x^3,   d = 0.2, c = 1, g = 0.5, energy E = 1/2.
Unperturbed, every orbit has period 2pi except the y-mode (x = px = 0), which has period pi. The orbit space is a
sphere with one cone point, the y-mode. x^2 y is the resonant (Fermi) term; g x^3 averages to zero at first order
but breaks x -> -x, which would otherwise make every orbit's monodromy a square, as P did for the 1:1 system.

Count rule (Frauenfelder-Koh-Moreno): count good orbits of period ~2pi with E + I - H. The y-mode appears there as
its double cover, which is bad (left out) when the y-mode itself is negative-hyperbolic.
Averaging near the cone point (w = x-amplitude * e^{i alpha}, the y-mode at amplitude b0, b0^2 = E/2):
  <V1> ~ const + |w|^2 (D + R cos 2 alpha),  D = 5d/8 - 3 b0^2/16 + c b0^2/4,  R = kappa b0/4
  -> cone point an extremum (y-mode elliptic) for |R| < |D|, a saddle (y-mode negative-hyperbolic: its
     parametric-resonance tongue) for |R| > |D|;  kappa* = 4|D|/b0 = 1.125.

Predictions, fixed before any orbit was computed:
  R1  kappa sweep 0.05 -> 2.5 at eps = 0.01, and eps sweep at kappa = 2 (up to 0.9 of the star-shape limit, max 1):
      good-orbit count E + I - H = 2 at every counted point
  R2  near kappa* the y-mode turns elliptic -> negative-hyperbolic and one new orbit of period ~2pi appears;
      the naive count (bad double cover counted as hyperbolic) drops from 2 to 1 there
"""
import numpy as np
from scipy.optimize import brentq

D_, C_, G_, EN = 0.2, 1.0, 0.5, 0.5
TWIN = (0.7*2*np.pi, 1.3*2*np.pi)
SWEEP = "kappa"          # "kappa": p = kappa at EPS0; "eps": p = eps at KAPPA_E
EPS0, KAPPA_E = 0.01, 2.0
B0 = np.sqrt(EN/2)
DCOEF = 5*D_/8 - 3*B0**2/16 + C_*B0**2/4
KAPPA_STAR = 4*abs(DCOEF)/B0


class Res12:
    def __init__(self, eps, kappa):
        self.eps, self.kappa = eps, kappa

    def V1(self, x, y):
        return self.kappa*x*x*y + D_*(x*x - y*y) + x**4 + y**4 + C_*x*x*y*y + G_*x**3

    def rhs(self, X):
        x, y, px, py = X
        e, k = self.eps, self.kappa
        return np.array([px, py,
                         -x - e*(2*k*x*y + 2*D_*x + 4*x**3 + 2*C_*x*y*y + 3*G_*x*x),
                         -4*y - e*(k*x*x - 2*D_*y + 4*y**3 + 2*C_*x*x*y)])

    def jacv(self, X):
        x, y = X[0], X[1]
        e, k = self.eps, self.kappa
        J = np.zeros((X.shape[1], 4, 4))
        J[:, 0, 2] = J[:, 1, 3] = 1
        J[:, 2, 0] = -1 - e*(2*k*y + 2*D_ + 12*x*x + 2*C_*y*y + 6*G_*x)
        J[:, 2, 1] = J[:, 3, 0] = -e*(2*k*x + 4*C_*x*y)
        J[:, 3, 1] = -4 - e*(-2*D_ + 12*y*y + 2*C_*x*x)
        return J

    def H(self, X):
        x, y, px, py = X
        return 0.5*(px*px + x*x) + 0.5*(py*py + 4*y*y) + self.eps*self.V1(x, y)

    def gradH(self, X):
        f = self.rhs(X)
        return np.array([-f[2], -f[3], f[0], f[1]])

    def wrap(self, dX):
        return np.asarray(dX, float)

    def canon(self, m):
        return np.asarray(m, float)

    def ok(self, X):
        return np.abs(X).max() < 5

def make(p):

def star_limit(kappa, eps_grid):
    """Largest eps in eps_grid for which every ray from the origin crosses H = E once (energy surface star-shaped)."""
    rng = np.random.default_rng(0)
    n = rng.normal(size=(200000, 4)); n /= np.linalg.norm(n, axis=1, keepdims=True)
    nx, ny, npp = n[:, 0], n[:, 1], (n[:, 2:]**2).sum(1)
    last = None
    for e in eps_grid:
        A2 = npp/2 + (nx**2 + 4*ny**2)/2 + e*D_*(nx**2 - ny**2)
        B3 = e*(kappa*nx**2*ny + G_*nx**3)
        C4 = e*(nx**4 + ny**4 + C_*nx**2*ny**2)
        disc = 9*B3**2 - 32*A2*C4
        two = (A2 > 0) & (disc > 0) & (B3 < 0)
        sq = np.sqrt(np.where(two, disc, 0))
        t1, t2 = (-3*B3 - sq)/(8*C4), (-3*B3 + sq)/(8*C4)
        f = lambda t: A2*t**2 + B3*t**3 + C4*t**4
        if (two & (f(t1) > EN) & (f(t2) < EN)).any() or (A2 <= 0).any():
            break
        last = e
    return last


def avg_f(kappa, P, Q):
    """<V1> in the pole chart (P, Q) = b (cos psi, sin psi), x = sqrt(s) cos t, y = b cos(2t - psi), s = 2E - 4b^2."""
    b2 = P*P + Q*Q
    s = 2*EN - 4*b2
    return kappa*s*P/4 + D_*(s - b2)/2 + 3*(s*s + b2*b2)/8 + C_*s*b2/4


def avg_critical(kappa):
    """Regular critical points of <V1>. For kappa != 0, df/dQ = 0 forces Q = 0, so they are the roots of
    d/dP f(P, 0) on (-b0, b0); type from the 2x2 Hessian. The cone point (y-mode) is always critical:
    extremum if |R| < |D|, saddle if |R| > |D|."""
    h = 1e-6
    g = lambda P: (avg_f(kappa, P + h, 0) - avg_f(kappa, P - h, 0))/(2*h)
    Ps = np.linspace(-B0, B0, 4001)[1:-1]
    gv = np.array([g(P) for P in Ps])
    pts = []
    for i in np.nonzero(np.sign(gv[:-1]) != np.sign(gv[1:]))[0]:
        P = brentq(g, Ps[i], Ps[i + 1], xtol=1e-14)
        fpp = (avg_f(kappa, P + 1e-4, 0) - 2*avg_f(kappa, P, 0) + avg_f(kappa, P - 1e-4, 0))/1e-8
        fqq = (avg_f(kappa, P, 1e-4) - 2*avg_f(kappa, P, 0) + avg_f(kappa, P, -1e-4))/1e-8
        kind = "saddle" if fpp*fqq < 0 else ("min" if fpp > 0 else "max")
        pts.append(dict(s=float(2*EN - 4*P*P), psi=0.0 if P >= 0 else float(np.pi), kind=kind))
    R = kappa*B0/4
    cone = "saddle" if abs(R) > abs(DCOEF) else ("min" if DCOEF > 0 else "max")
    return pts, cone


def seeds(p, sy):
    out = []
    pred = avg_critical(eps_kappa(p)[1])[0]
    for q in pred:                                        # predicted orbits first
        a, b = np.sqrt(q["s"]), np.sqrt(max(EN - q["s"]/2, 0)/2)
        X = np.array([a, b*np.cos(-q["psi"]), 0.0, 2*b*np.sin(q["psi"])])
        out.append((brentq(lambda k: sy.H(k*X) - EN, 0.3, 2.0)*X, 2*np.pi))
    ends = [2*EN*f for k in (1, 2, 3) for f in (10.0**-k, 1 - 10.0**-k)]   # rings near the y-mode and the pole
    for s in np.unique(np.concatenate([np.linspace(0, 2*EN, 21), ends])):  # s = x-amplitude^2; 0 = y-mode, 2E = pole
        for psi in np.linspace(0, 2*np.pi, 20, endpoint=False) if 0 < s < 2*EN else [0.0]:
            a, b = np.sqrt(s), np.sqrt(max(EN - s/2, 0)/2)

            try:
                X = brentq(lambda k: sy.H(k*X) - EN, 0.3, 2.0)*X
            except ValueError:
                continue
            out.append((X, 2*np.pi))
    return out

import json

def fy(k):
    if k > 0:
        return -np.arccosh(1 + k/2)/np.pi
    if k < -4:
        return 1 + np.arccosh(-1 - k/2)/np.pi
    return np.arccos(np.clip(1 + k/2, -1, 1))/np.pi


def r4(v):
    return round(float(v), 4)


def same(a, b):
    return (abs(a["T"] - b["T"]) < 1e-6 and np.linalg.norm(np.subtract(a["center"], b["center"])) < 1e-5
            and np.linalg.norm(np.subtract(a["mean"], b["mean"])) < 1e-5)


def one_to_one(path):
    D, out = json.load(open(path)), {}
    search = {(n, round(e, 12)): f for n, e, f in D["search"]}
    for name in D["cases"]:
        grid, brs = D["grids"][name], D["continuation"][name]
        tracks = [[r4(fy(r["k"])) for r in b["rows"]] for b in brs]
        ttype = ["".join(r["full"][0] if r["full"] != "unsure" else "u" for r in b["rows"]) for b in brs]
        extra, cnt, counted = [], {"E": [], "H": [], "I": []}, 0
        for i, e in enumerate(grid):
            F = [b["rows"][i] for b in brs if i < len(b["rows"])]
            for f in search[(name, round(e, 12))]:
                if not any(same(f, g) for g in F):
                    F.append(f)
                    extra.append([r4(e), r4(fy(f["k"])), f["full"][0]])
            for t in "EHI":
                cnt[t].append(sum(r["full"] == t for r in F))
            counted += not any(r["full"] == "unsure" or r.get("quot") == "unsure" for r in F)
        out[name] = dict(x=[r4(e) for e in grid], tracks=tracks, ttype=ttype, extra=extra, count=cnt, counted=counted,
                         events=[[k, r4(e)] for k, e in D["events"][name]],
                         kinds=[b["kind"] for b in brs])
    return out
